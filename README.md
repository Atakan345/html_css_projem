# Cafe Menu Website

This is a simple HTML & CSS project that showcases a responsive cafe menu design.  
The purpose of this project is to demonstrate basic web layout, typography, and styling skills using only HTML and CSS.

## 🧠 Features

- Responsive layout
- Clean and minimal design
- Semantic HTML structure
- Custom styling with external CSS
- Organized sections: Header, Menu, Footer

## 🔧 Technologies Used

- HTML5
- CSS3
- Visual Studio Code
